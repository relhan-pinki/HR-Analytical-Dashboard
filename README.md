# HR Analytical Dashboard

## 📊 Project Overview
This project is an interactive HR Analytical Dashboard developed in Microsoft Power BI to analyze employee workforce, attrition, departments, salary slabs, job roles, employee demographics, job satisfaction, and total experience.
The dashboard provides a consolidated view of workforce size, active employees, attrition, employee demographics, and department-wise workforce distribution.
It includes interactive filters for Department, Age Group, Business Travel, and Education Field.


---


## 🎯 Objectives
- Analyze the overall employee workforce.
- Identify active employees and employee attrition.
- Calculate and monitor attrition rate.
- Analyze attrition across different departments.
- Compare attrition across salary slabs.
- Understand attrition by gender.
- Analyze employee distribution across age groups.
- Compare employee counts by gender.
- Analyze attrition by job role and job satisfaction.
- Examine department-wise employee distribution.
- Understand attrition by total work experience.
- Create an interactive HR analytics dashboard.

## 🚀 How to Use project
